## Routing

An orchestrator routes each query to one of six domain experts, wired as AgentTools
on a root agent. Four of them are RAG backed. The other two, gold loan and KYC
documents, have no knowledge base, so no grounding rule fires for them and they
answer from the model directly.

## Evaluating it

The evaluation stack runs against the development environment. Opik 2.0.47, self
hosted, collects traces; an LLM as judge scores RAGAS style metrics using
gemini-2.5-flash against a golden QA dataset of 109 items.

RAGAS style is doing real work in that sentence: the dimensions are RAGAS shaped
but the RAGAS library is not integrated — the judge is custom.

A custom LiveTurnTracer captures per turn spans across the four RAG backed
experts.
